# CapFlow — installers and updates

Download the latest Windows installer from **[Releases](../../releases/latest)**.

- `CapFlow-Setup-<version>.exe` — the full installer (everything bundled; no Node, Python or extra downloads needed)
- `CapFlow-code-<version>.zip` + `capflow-update.json` — used by the app's own updater

Website: https://capflow-studio.vercel.app

The application source code is private; this repository only carries the released builds.
